# 🤝 Contributing to RL Dynamic Pricing

Thank you for your interest in contributing to this project!

This repository demonstrates the implementation of Reinforcement Learning techniques for solving a Dynamic Pricing problem using custom environments, classical RL algorithms, and Deep Reinforcement Learning.

---

# 📋 Development Workflow

1. Fork the repository.
2. Clone your fork locally.
3. Create a new feature branch.

```bash
git checkout -b feature/your-feature-name
```

4. Make your changes.
5. Test your implementation.
6. Commit using clear commit messages.
7. Push your branch.

```bash
git push origin feature/your-feature-name
```

8. Open a Pull Request.

---

# 📝 Coding Guidelines

Please follow these practices:

- Follow PEP 8 coding standards.
- Use meaningful variable and function names.
- Keep functions modular.
- Add comments where necessary.
- Avoid unnecessary code duplication.

# 🧪 Testing

Before submitting a Pull Request:

- Ensure the code executes successfully.
- Verify all notebooks run without errors.
- Check generated plots and result files.
- Confirm no unnecessary files are committed.

---

# 📖 Documentation

If you introduce new functionality:

- Update the README if required.
- Add comments where appropriate.
- Keep documentation clear and concise.

---

# 🐛 Reporting Issues

When reporting a bug, please include:

- Operating System

- Error Message
- Steps to Reproduce
